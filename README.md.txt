# HR Workforce Analytics Project (R)

## Project Overview
This project analyzes workforce structure, salary distribution, and compensation alignment using R and ggplot2.

## Objectives
- Examine workforce experience structure
- Analyze salary band distribution
- Assess relationship between experience and salary
- Identify inequality and dispersion
- Compute correlation between experience and salary

## Tools Used
- R
- ggplot2

## Key Findings
- Senior-dominant workforce structure
- Balanced salary bands
- Very strong positive relationship between experience and salary (r ≈ 0.97)
- No extreme compensation outliers
